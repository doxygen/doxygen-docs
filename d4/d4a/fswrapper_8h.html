Detailed Description

Selects the filesystem implementation used by doxygen.

The standard library's std::filesystem is used when it is available and usable without extra link libraries. Otherwise the bundled ghc::filesystem (deps/filesystem) is used as a fallback, in particular for:

  • GCC 8 / libstdc++ 8 (e.g. RHEL 8), where std::filesystem needs -lstdc++fs
  • LLVM libc++ before version 9, where it needs -lc++fs
  • macOS deployment targets before 10.15, which lack std::filesystem

Defining DOXYGEN_USE_GHC_FILESYSTEM forces the use of ghc::filesystem.

Doxygen uses UTF-8 encoded std::string paths everywhere. ghc::filesystem treats narrow strings as UTF-8 on all platforms, but std::filesystem uses the active (ANSI) code page on Windows. Always convert between strings and paths using toFsPath() and fromFsPath(), so non-ASCII file names keep working on Windows.
